# REACTION MASTER

スマホ縦画面（9:16）向けの反射神経ゲーム。ランダムな位置に現れる円形ターゲットを素早くタップしよう。
漆黒 × ネオングリーンの近未来アーケード風デザイン。PCでは画面中央に縦長フレームで表示されます。

## 遊び方
1. タイトル画面で **SPEED TEST** または **MIND GAME** を選ぶ（MIND GAME はルール画面の後に START）
2. カウントダウン「3・2・1」→「GO!」の後、GO! が消えてから最初のターゲットが出現
3. SPEED TEST：現れた円をできるだけ速くタップ（円の外をタップするとミス）
   MIND GAME：色に応じて「タップ」「待つ」「2回タップ」を判断
4. 終了するとリザルト画面へ。結果を 𝕏 でシェアできます

## モード
タイトル画面で **SPEED TEST** と **MIND GAME** を選べます。

- **SPEED TEST**：ターゲットを20回タップするまでの反応速度を計測
- **MIND GAME**：色によって正しい操作が変わる判断力テスト（30ラウンド）

### MIND GAME のルール
開始前にルール画面で色ごとの操作を確認できます。ランダムな位置に1つずつターゲットが現れます。

| 色 | 操作 | 判定 |
|---|---|---|
| 緑 | 1回タップ | 出現から1.5秒以内にタップで成功 |
| 赤 | 待つ | 1.0秒間タップせずに待てば成功。タップするとミス |
| 黄 | 2回タップ | 出現から1.5秒以内に2回タップ（間隔0.5秒以内）で成功。1回目ではターゲットは消えない |

- 時間切れ・間違った操作はミス。1ラウンドにつき成功かミスを必ず1回だけ記録します
- ターゲット以外の場所のタップは記録しません
- 色は各10回ずつ、ランダムな順番で出現。同じ色は最大2回までしか続きません
- 色だけでなく形でも区別できます（緑＝照準、赤＝進入禁止のバー、黄＝二重リング）

**スコア**（1ラウンドあたり）
- 成功：100点
- 速さボーナス（緑・黄のみ）：(1500 − 操作にかかった時間ms) ÷ 15（最大100点）
- 連続正解ボーナス：(連続数 − 1) × 10（最大90点）

**結果画面**：スコア・正解数・ミス数・正解率・平均時間（緑・黄の正解操作のみ。赤の待機成功は含めない）・最大連続正解数・最高スコア（ブラウザに保存）

## 主な機能
- **HUD**：経過時間（TIME）・ヒット数（HIT）・直前の反応時間（LAST）・ミス数（MISS）と進捗バー
- **ヒット演出**：タップ位置から広がるネオングリーンの波紋（約0.2秒）と、ターゲットが縮んで消える演出（0.15秒）
- **効果音**：Web Audio API で生成する短い電子音（音声ファイル不要）
- **効果音 ON/OFF**：タイトル画面右上のスピーカーボタンで切り替え（設定はブラウザに保存）
- **BGM**：Web Audio API でプログラム生成したオリジナルのサイバー・テクノ曲（BPM124・8小節ループ、音声ファイル不要）
  - START / RETRY で再生 → ゲーム中はループ → 結果画面でフェードアウト、タイトルに戻ると停止
  - タイトル画面右上の音符ボタンで ON/OFF（設定はブラウザに保存）
  - ページを非表示にする・閉じると一時停止し、戻ると再開
- **音量スライダー**：タイトル画面の START ボタン上で BGM と効果音（SE）の音量を別々に調整（0〜100、設定はブラウザに保存）
  - どちらかのスライダーを動かしている間は BGM を試聴でき、離して約1.5秒後に止まる
  - 試聴中は SE（タップ音）が BGM の拍に合わせて鳴るので、BGM と SE の音量バランスを聴きながら調整できる
  - BGM が OFF のときは、SE スライダーを離したときに確認用の効果音が一度鳴る
  - ON/OFF ボタンが OFF のときはスライダーが薄く表示される
  - 曲は最初に一度だけ音声データに書き出し、ゲーム中はループ再生するだけなので、タップ判定や反応時間の計測に影響しません
- **触覚フィードバック（振動）**：設定ボタンはなし（対応端末では常に有効）
  - Android など `navigator.vibrate()` 対応ブラウザ：タップ成功時に 12ms の短い振動
  - iPhone Safari・PC など非対応環境：振動なしで通常どおり動作
    （iPhone Safari は Web から振動を発生させる公式の手段がありません。Safari の `switch` チェックボックスを使う手法も試しましたが、実機で振動しなかったため採用していません）
- **自己ベスト**：ブラウザ（localStorage）に保存し、タイトル・リザルト画面に表示

## オンラインランキング
タイトル右上のトロフィーボタン、または結果画面の **RANKING** から見られます。SPEED TEST と MIND GAME で別々のランキングです。

**登録できるプレイ**
- SPEED TEST：ミス0回のプレイだけ
- MIND GAME：30問すべて正解したプレイだけ
- ミスが1回でもあれば登録できません（結果画面に「対象外」と表示）

**順位**：平均反応時間（小数第1位まで）が短い順。同じタイムなら先に記録した人が上。

| モード | 平均反応時間の計算 |
|---|---|
| SPEED TEST | 20回のタップの反応時間の平均 |
| MIND GAME | 緑10回（出現〜タップ）＋ 黄10回（出現〜**1回目**のタップ）の平均。赤は含めない |

- 黄は2回目までの時間にすると連打の間隔が上乗せされ、緑と公平に比べられないため、1回目のタップまでを反応時間としています（2回目は成功の条件としてだけ使います）
- MIND GAME の結果画面の「AVG TIME」はこれまでどおり（黄は2回目まで）で、ランキング用の値は結果画面のランキング欄に表示されます

**評価ランク**：SPEED TEST は下の「ランク判定」の表、MIND GAME は次の表（暫定値）

| ランク | S | A | B | C | D | E | F |
|---|---|---|---|---|---|---|---|
| MIND GAME の平均 | 450未満 | 520未満 | 600未満 | 700未満 | 800未満 | 950未満 | それ以上 |

**自己ベスト**：プレイヤーごと・モードごとに一番速い記録を1件、サーバーと端末（localStorage）の両方に保存。通信できなかった記録は、次にランキングを開いたときに自動で送り直します。

**プレイヤー名**：初めて登録するときに入力（12文字まで）。ランキング画面の名前をタップすると変更できます。
プレイヤーは端末ごとのランダムなIDで区別します（IDは画面には表示されません）。

### オンラインランキングの準備（Supabase）
サーバーには無料で使える [Supabase](https://supabase.com/) を使います。設定するまではランキングは「準備中」と表示され、ゲームと端末内の自己ベストは通常どおり動きます。
1. Supabase でプロジェクトを作成する
2. 「SQL Editor」に `supabase/ranking.sql` の中身を貼り付けて「Run」
3. 「Project Settings → API」の **Project URL** と **anon（または publishable）キー** を、`ranking.js` 先頭の `RANKING.supabaseUrl` / `RANKING.supabaseAnonKey` に書き込む

- anon / publishable キーはブラウザに公開する前提の鍵なので、GitHub に載せても問題ありません。**service_role（secret）キーは絶対に書かないでください**
- ブラウザからはテーブルを直接読み書きできず、用意した3つの関数（送信・取得・名前変更）だけを使えます
- 送信するのは1回ごとの反応時間で、平均・順位はサーバー側で計算し直します。回数が違う記録や、100ms未満などありえない値を含む記録は受け付けません
- ブラウザで動くゲームのため、改造したプログラムからの不正な送信を完全に防ぐことはできません。不適切な名前や記録は Supabase の「Table Editor」の `ranking_best` から削除できます

## 反応時間の計測について
- 計測はターゲットが**出現した瞬間**から、タップ（`pointerdown`）した瞬間まで
- カウントダウン中・GO! 表示中のタップはヒットにもミスにもなりません
- ヒットした瞬間にそのターゲットは判定から外れるため、二重にヒット判定されることはありません
- 演出や効果音は計測値の確定後に実行されるので、反応時間には影響しません
- 命中率 = ヒット数 ÷（ヒット数 + ミス数）

## ファイル構成
```
index.html  … 画面の構造（タイトル / SPEED TEST / MIND GAME のルール・プレイ・結果）
style.css   … デザイン・アニメーション（黒 × ネオングリーン）
script.js   … SPEED TEST と共通処理（画面切り替え・効果音・BGM・設定の保存）
mind.js     … MIND GAME（script.js の後に読み込む）
ranking.js  … オンラインランキング（mind.js の後に読み込む）
supabase/ranking.sql … ランキング用サーバー（Supabase）の設定SQL
manifest.webmanifest … ホーム画面に追加したときのアプリ名・アイコン・表示方法
favicon.png / apple-touch-icon.png / icon-192.png / icon-512.png … アプリアイコン
```

## カスタマイズ
MIND GAME の設定（ラウンド数・制限時間など）は `mind.js` の先頭の `MIND` で変更できます。
SPEED TEST と共通の設定は `script.js` の先頭にある設定値で調整できます。

| 設定 | 内容 | 初期値 |
|---|---|---|
| `CONFIG.totalTargets` | クリアに必要なヒット数 | 20 |
| `CONFIG.countdownFrom` | カウントダウン秒数 | 3 |
| `CONFIG.missPenaltyMs` | ランク判定でミス1回ごとに加算するペナルティ | 30 |
| `CONFIG.goDurationMs` | GO! の表示〜フェードアウトの長さ（ms） | 650 |
| `CONFIG.hitVibrateMs` | タップ成功時の振動の長さ（ms・Android） | 12 |
| `CONFIG.defaultBgmVolume` | BGM の初期音量（0〜1） | 0.3 |
| `CONFIG.defaultSfxVolume` | 効果音の初期音量（0〜1） | 1.0 |
| `CONFIG.bgmFadeOutSec` | 結果画面へ移るときの BGM フェードアウト秒数 | 1.2 |

BGM と効果音の音量は、タイトル画面のスライダーで別々に調整できます（プログラムからは `setBgmVolume(0〜1)` / `setSfxVolume(0〜1)`）。
曲そのもの（テンポ・コード進行・音色）は `script.js` の `renderBgm()` で変更できます。
| `RANKS` | ランクの基準値と称号 | 上表のとおり |

※ `goDurationMs` を変更する場合は、`style.css` の `.countdown.pop.go` の `animation` の秒数も合わせて変更してください。

## 動作環境・注意
- iPhone の縦画面を最優先に調整（ノッチ・ホームバーを避けて表示）
- iPhone はサイレントスイッチが ON だとブラウザの効果音・BGM が鳴りません
- iPhone Safari の制限により、音声は START / RETRY などのタップをきっかけに開始します
- フォントは Google Fonts（Orbitron / Noto Sans JP）を使用。外部の有料素材は使用していません
